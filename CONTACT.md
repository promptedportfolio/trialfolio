# Contact

Nathan Slaughter is the author of Trial Folio and the licensor of the material he has the right to license. His address is **[git@nathanslaughter.com](mailto:git@nathanslaughter.com)**.

## How to get in touch

| What you want to do | Where it goes |
|---|---|
| Report a bug | [Open a bug report](https://github.com/promptedportfolio/trialfolio/issues/new?template=bug-report.yml) |
| Suggest a feature | [Open a feature request](https://github.com/promptedportfolio/trialfolio/issues/new?template=feature-request.yml) |
| Ask a question about using Trial Folio, or about how it's built | [Ask a question](https://github.com/promptedportfolio/trialfolio/issues/new?template=question.yml) |
| Point out a documentation problem | [Report a documentation problem](https://github.com/promptedportfolio/trialfolio/issues/new?template=documentation.yml) |
| Report a security problem | Email, never a public issue. See [security problems](#security-problems). |
| Ask about licensing, or request written permission | Email. See [permission requests](#permission-requests). |
| Propose a code change | Open a bug report or feature request instead. Outside pull requests aren't accepted yet; see [CONTRIBUTING.md](CONTRIBUTING.md). |

**Issues are public.** Never post your Portfolio123 API ID or API key. Don't post Portfolio123 data either, such as responses, exports, or reports that contain it: Portfolio123's terms restrict sharing it.

## Security problems

Email **[git@nathanslaughter.com](mailto:git@nathanslaughter.com)** with "Security" in the subject. Describe the problem and how to reproduce it, without real credentials. Don't open a public issue.

## Permission requests

Send licensing questions and requests for written permission to **[git@nathanslaughter.com](mailto:git@nathanslaughter.com)**.

**Sending a request does not grant permission.** You have permission only after you receive an express written grant from Nathan Slaughter. An inquiry, silence, an automatic reply, attribution, a donation, or the purchase of an unrelated product is not permission.

The [LICENSE](LICENSE) (`LicenseRef-NSPRL-1.0`) controls. The [licensing policy](docs/licensing-policy.md) explains it in plain terms.

### When you need written permission

Ask before you act if any of these apply:

- **You are a Professional User.** That means any one or more of the following:
  - you have more than US $5,000,000 in liquid assets, not counting retirement accounts
  - you make investment decisions for anyone other than yourself and your family members
  - reselling research about stocks provides more than half of your total income
- **You would use Trial Folio for an organization**, including for your employer.
- **You would put Trial Folio's code, or code based on it, into any public project or published code.** This applies whether the project is free, paid, commercial, nonprofit, source available, or open source.
- **You would publish, redistribute, or sublicense Trial Folio**, or supply it to anyone else. This includes public forks outside what LICENSE section 5.4 allows on GitHub, vendored source, packages, binaries, container images, notebooks containing copied code, and hosted services.
- **You would let someone other than your family members use Trial Folio through an interface you run.**
- **You no longer qualify for the personal research grant** and want to keep using Trial Folio.

You don't need permission to share or publish reports Trial Folio generated for you, as long as the notice in each report stays intact and unaltered. You remain responsible for your data provider's terms, including Portfolio123's. Trial Folio's license grants no Portfolio123 rights. Sharing a report that contains Portfolio123 data publicly may need Portfolio123's consent.

### What to include in a request

- Your name, and your organization if the request is for one
- The use you're asking about, and why the personal research grant doesn't cover it (for example, which Professional User condition applies)
- The scope you need: which parts of Trial Folio, which versions, how many people, and for how long
- For publication or distribution: where, to whom, whether the code is modified, and how you'll keep the license and notices intact
- How to reach you

Don't send account balances, statements, tax records, or the names of family members. Say which condition applies; you don't need to prove it.

### What a grant identifies

A written grant comes from Nathan Slaughter, sent from or signed as above. It identifies:

- the recipient
- the permitted scope
- any duration
- any publication, distribution, or sublicensing rights

A grant covers only what it states. Permission to use Trial Folio as a Professional User or for an organization doesn't include permission to publish or distribute code unless the grant says so.
