- **The resume,** without credentials: exit 0, `completed`, `sessions/2/`, nothing sent, and no ranking lock taken. In the second run it ran under the full guard; after the first, by hand.
- **The account's ranking systems:** the owner compared them in the Portfolio123 website before and after. After each run, none but `ApiRankingSystem` had changed (R04-AC07, R04-AC09).

In all, the live check used 38 credits, 19 for each run, each within its approved budget.
