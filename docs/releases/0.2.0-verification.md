## Limitations

- Everything ran on one Mac, as for 0.1.0. The Windows paths are checked only from CPython's source and Microsoft's documentation.
- The reference check reviewed the one run the live check wrote, which has a saved response. So its branch for a run without one, such as a run whose authentication failed, didn't run. `tests/core/test_differences.py` checks the same behavior with runs built over the fake server.
- Links that name the version's tag, such as a report's link to the LICENSE and the starter README's link to the user guide, give `v0.2.0`, so they work only once 0.2.0 is tagged.
