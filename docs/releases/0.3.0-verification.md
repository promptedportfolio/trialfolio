# Release 0.3.0: verification record

This is the record that [release 0.3.0's verification commands](0.3.0-experiments.md#verification-commands-and-expected-evidence) call for. It gives each command's date, versions, and outcome, and the evidence for each acceptance criterion. R03-T11 created it. It records only what was run: a command that hasn't run says so.

## Environment

All of these ran on 2026-10-11, on the branch `test/r03-t11-experiment-tests`, based on `main` at 524d8ef.

- **Machine:** macOS 26.6.2 (25G83), arm64. Nothing ran on Linux or Windows for this record. The `check` workflow runs `scripts/check` on GitHub, on Ubuntu, for the pull request.
- **Python:** 3.14.8, the interpreter uv chose for the branch's worktree, for every command below. The default suite also ran on 3.12.13, the oldest version Trial Folio supports, in an environment of its own, as [below](#python-312).
- **Tools:** uv 0.12.23, Git 2.54.0, pytest 9.1.1, ruff 0.16.10, pyright 1.1.414.
- **Packages:** `p123api` 3.1.0, `requests` 2.34.2, and `urllib3` 2.8.0, the [verified versions](../contracts.md#plan-contents); `pydantic` 2.13.5, `pydantic-core` 2.46.5, `PyYAML` 6.0.3, and `rfc8785` 0.1.4, as `uv.lock` pins them.
- **Trial Folio's version:** 0.3.0, the package's version since R03-T05 completed the specification ([D-26](../spec.md#decisions)). Every command below ran under it, and the committed historical experiment gives it.
