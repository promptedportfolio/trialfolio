# Trial Folio user guide

This guide is now the [user manual](https://promptedportfolio.github.io/trialfolio/), which describes Trial Folio as tutorials, how-to guides, reference, and explanation. Its pages are in [`manual/`](../manual/index.md), at the repository's root, and [user-manual.md](user-manual.md) is its plan. Release 0.4.0's documentation task, R04-T14, turned this guide into a page that points there, as [D-35](spec.md#decisions) decided. The manual describes Trial Folio as the repository's `main` branch has it, release 0.4.0's ranking definitions and snapshots included: [vary a ranking system's weights](https://promptedportfolio.github.io/trialfolio/how-to/vary-a-ranking-systems-weights/) and [take a ranking snapshot](https://promptedportfolio.github.io/trialfolio/how-to/take-a-ranking-snapshot/).

**For a tagged version up to `v0.3.0`,** read this guide at that tag, which describes it, such as [the user guide at `v0.3.0`](https://github.com/promptedportfolio/trialfolio/blob/v0.3.0/docs/user-guide.md). A later tag holds the manual's pages for its version, in its `manual/` folder.

This page owns no requirement. The documents in `docs/` define Trial Folio's behavior, and the manual describes it ([the documents](README.md#documents)).
