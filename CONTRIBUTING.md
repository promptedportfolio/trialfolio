# Contributing

Thank you for your interest in Trial Folio.

**Trial Folio doesn't accept outside changes yet, to code or to documentation.** Its license lets Nathan Slaughter distribute only work he holds the rights to. No contributor terms exist yet that would give him those rights over someone else's changes ([LIC-14](docs/licensing-policy.md#lic-14-contributions)). Pull requests from anyone else are closed without being merged or copied.

You can still help:

- **Report bugs, suggest features, ask questions, and point out documentation problems.** [CONTACT.md](CONTACT.md) links to the right form for each.
- **Report security problems privately,** by email, as [CONTACT.md](CONTACT.md#security-problems) describes.

**About forks.** You may view and fork this repository on GitHub, as GitHub's terms allow. LICENSE section 5.4 sets the limits: a fork gives you no right to publish changes, and no right to use Trial Folio beyond the license's personal research grant.
